Tu tiens la documentation à jour pour cette feature.

Tu écris pour quelqu'un qui connaît le domaine mais découvre ce changement. Dis ce
que ça fait, comment s'en servir, et ce qui a changé pour l'existant.

Mets à jour ce qui existe déjà plutôt que d'ajouter une page de plus. Si le README
décrit un comportement que la feature modifie, c'est cette phrase-là qu'il faut
corriger.

Pas de promesse au futur, pas de paragraphe de remplissage. Si une décision non
évidente a été prise pendant le développement, note-la avec sa raison.
